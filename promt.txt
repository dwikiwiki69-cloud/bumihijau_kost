# 1. CORE ARCHITECTURE & SECURITY RULES (NON-NEGOTIABLE)
1. **Strict Multi-Tenancy:** Every database query MUST be isolated by `organization_id` (milik Owner). Data from one kost owner must never leak to another.
2. **Role-Based Access Control (RBAC):** Implement strict middleware and UI guards for 3 roles:
   - `OWNER` (Super Admin): Full access across all branches, financial reports, net profit analytics, staff management, expense verification, and audit logs.
   - `ADMIN_KOST` (Field Operator): Restricted operational access. Can check-in/out tenants, view room payment status, resolve maintenance tickets, and **submit** operational expenses. **STRICTLY BLOCKED** from viewing total revenue, net profit reports, audit logs, or deleting/editing submitted expenses.
   - `TENANT` (Anak Kost): Access via unique magic-link token (no password/app install required) to view invoices, download receipts, and submit facility complaints.
3. **Immutable Records & Audit Trail:**
   - Once `ADMIN_KOST` submits an expense, they **cannot edit or delete it**.
   - Every critical mutation (create/update/delete/approve/flag/void) must write an entry to `audit_logs` capturing `user_id`, `role`, `action`, `entity_type`, `entity_id`, `metadata` (before/after JSON), and `timestamp`.

# 3. KEY BUSINESS WORKFLOWS & UI/UX REQUIREMENTS
1. **Admin-to-Owner Expense Sync (Core USP):**
   - **Admin UI:** Mobile-first, ultra-simple interface with large touch targets. Form requires category, amount, optional room selector, notes, and **mandatory receipt/work photo upload** (include client-side image compression before upload).
   - **Real-Time Sync & Net Profit:** Submitting an expense immediately updates the Owner's Cashbook and recalculates **Net Profit** (`Total Paid Invoices - Total Non-Void Expenses`).
   - **Owner Verification Queue:** Owner sees new expenses marked `PENDING_REVIEW` and can click **Approve**, **Flag (Need Clarification + Comment)**, or **Void**.
   - **Approval Threshold:** If an Admin tries to log a maintenance expense above `property.expense_approval_threshold`, prompt them to submit an `Expense Request` for Owner approval first.
2. **Interactive Room Grid Dashboard:**
   - Visual color-coded grid per property: Green (`VACANT`), Blue (`OCCUPIED - PAID`), Yellow (`DUE_SOON`), Red (`OVERDUE`).
3. **Owner Executive Analytics:**
   - Filterable cashflow & expense history by Property Branch, Category (e.g., total AC cleaning & electricity costs), Room Number, and Admin name.
   - Exportable Financial Report (CSV/PDF-ready view).
4. **Tenant Magic-Link Portal:**
   - Public route `/portal/[magic_link_token]` allowing tenants to view billing status, download digital receipts, and submit maintenance tickets with photos.
